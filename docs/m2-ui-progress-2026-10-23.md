# M2 接入引导与试运行交互实施记录

日期：2026-10-23。依据 [参考源码研究](./references/agent-teams-ai-2026-10-23.md) 改善已有 M2 功能；不改变原生接入、隔离和任务审查的验收边界。

## 接入方式与配置状态

- 模型连接与订阅账号页共用 API / Coding Plan、GPT 官方账号、Claude 官方账号三种入口；选择官方账号会切换并定位相应账号卡片，不自动登录、检查授权或请求模型。
- API 配置显示保存、格式检查、工具验证和绑定角色四项状态。保存不当作已连通；验证只对应本次表单，编辑后撤销旧结果。未保存的修改不能通过引导直接跳到角色绑定。
- 账号卡片分别展示官方工具、账号授权和编码执行状态。即便已授权，仍可能未满足编码执行条件；Claude 登录继续禁用。
- 异步检查/验证绑定当前表单代际，切换或编辑后到达的旧结果不会覆盖新配置或显示验证通过。
- 没有增加模型渠道、自动付费验证或自动读取宿主授权；现有角色正常窗口每行三张布局保持。

验证：全部 11 项 UI 测试、TypeScript/生产构建、9 项桌面测试、macOS arm64 打包及打包启动/重启冒烟通过。独立 QA 数据目录 `output/ui-connection-guide-qa-20261023/` 中实际查看 API 接入状态和 Claude 入口定位，确认未就绪说明与禁用操作可见；QA 应用已退出。未使用用户工作数据或发起真实模型请求。

前端仍有既有的大包体积告警，当前包未签名/公证。M2 原生执行验收状态见 [M2 记录](./m2-report.md)。

## 试运行快照与持久事件交互

- 试运行后自动收起输入区域，详情按“输出与快照 / 运行事件 / 只读工具”切换；展示本次连接和模型快照、资料范围、开始/保存时间、请求次数与上限、已处理模型回合及工具检查点数。
- 复用现有项目 SSE 和持久事件；仅接收所选项目/运行的 `run.started`、`run.progress`、`run.finished`，按事件序号排序、去重，最多显示最近 200 条。重连与历史回放只更新展示，不发起模型操作。
- 工具页展示已保存返回与待处理调用；未完成文本仍为预览，工具成功不等于正式任务验收通过。没有显示推理内容、凭证或工具参数。
- 历史详情采用选择代际，旧请求晚到不能覆盖新选择；事件快照同时按项目/运行分区，切换时不短暂展示上一运行的数据。订阅与状态读取失败分别提供显式重试；取消和计费提示下的显式继续保留。
- 关闭面板仅结束 UI 轮询和事件订阅，后台运行继续。当前试运行面板与项目工作区路由互斥，复用桌面既有的单项目事件订阅；后续常驻多面板时需统一订阅所有权，避免互相停止订阅。

验证：全部 15 项 UI 测试、TypeScript/生产构建、macOS arm64 打包、打包启动与重启通过；桌面主进程未修改，其 9 项测试已在本轮接入引导时通过。UI 回归覆盖事件过滤/排序/去重、订阅重试不计费、晚到历史详情、取消与显式继续。

M2 真实进程冒烟扩展为 7 项，新增实际 SSE 工具进度与终态读取、服务重启后相同序号回放，并确认没有新增模型请求。该测试仍仅请求本地合成服务。

实际桌面使用独立目录 `output/ui-run-details-qa-20261023/app/` 与无认证的回环合成网关，创建测试项目/连接/只读角色。一次运行记录 2 次请求预约、1 条 `get_status` 工具结果、7 条持久事件；实际切换输出、事件和工具页签通过。退出并重启后打开同一历史记录，输出、快照和 7 条事件恢复，请求预约仍为 2 次。单张角色卡仍只占三列中的一列。QA 应用与合成网关已停止，脱敏结果位于该忽略目录的 `result.json`，没有读取用户真实账号或请求服务商。

以上是已有只读试运行的展示与交互完善，不是 M3 正式任务图或完整多 Agent 调度。原生 GPT/Claude 验收缺口没有因此关闭。
