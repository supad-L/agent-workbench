## 接入方式与配置状态

- 模型连接与订阅账号页共用 API / Coding Plan、GPT 官方账号、Claude 官方账号三种入口；选择官方账号会切换并定位相应账号卡片，不自动登录、检查授权或请求模型。
- API 配置显示保存、格式检查、工具验证和绑定角色四项状态。保存不当作已连通；验证只对应本次表单，编辑后撤销旧结果。未保存的修改不能通过引导直接跳到角色绑定。
- 账号卡片分别展示官方工具、账号授权和编码执行状态。即便已授权，仍可能未满足编码执行条件；Claude 登录继续禁用。
- 异步检查/验证绑定当前表单代际，切换或编辑后到达的旧结果不会覆盖新配置或显示验证通过。
- 没有增加模型渠道、自动付费验证或自动读取宿主授权；现有角色正常窗口每行三张布局保持。

验证：全部 11 项 UI 测试、TypeScript/生产构建、9 项桌面测试、macOS arm64 打包及打包启动/重启冒烟通过。独立 QA 数据目录 `output/ui-connection-guide-qa-20261023/` 中实际查看 API 接入状态和 Claude 入口定位，确认未就绪说明与禁用操作可见；QA 应用已退出。未使用用户工作数据或发起真实模型请求。
