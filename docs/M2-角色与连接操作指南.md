# M2 角色与连接操作指南

更新：2026-10-23。本版已提供角色卡片、API 只读试运行、用量预算和 GPT 官方授权入口。实际写代码、并行派工与审查返工尚未接通；M2 原生编程工具执行尚未验收。

## 1. 启动

双击项目根目录的 **启动工作台.command**。通过此入口启动时，数据位于项目内的 `data/desktop/`，随本机项目保存在 D 盘。已有项目、资料与方案继续保留，数据库自动升级。基础项目操作见 [中文操作指南](./工作台-中文操作指南.md)。

## 2. 配置模型连接

1. 点击左侧 **模型连接 → 新增连接**。
2. 填写名称、协议、服务地址、默认模型、认证方式及 API Key。公司中转和国内 Coding Plan 都在这里配置；接口选择以服务商提供的说明为准。
3. GPT/DeepSeek 等普通 API 可选 **跟随本机网络**；需要独立出口的 API 选择 **使用指定出口代理** 并填写代理 URL。公司域名沿用本机 DNS 时，保持本机网络设置。这里只控制 API 请求路径。
4. 在模型设置中添加可用的模型 ID，填写工具调用能力。此项是你的配置声明；尚未测试的模型不会自动认定为支持工具。
5. 按需填写币种、输入与输出价格，以及账号并发上限。价格采用服务商的每百万 tokens 报价，由你维护；工作台不自动抓取实时价格。同一凭证的多个连接共用账号并发限制。
6. **更多设置** 可配置超时、输出上限、额外请求头、DeepSeek 方言等。折叠面板后保存也会保留这些值。明文 HTTP 只用于明确允许的本地测试，常规服务使用 HTTPS。
7. 点击 **检查配置** 核对端点，再点击 **保存连接**。检查与保存均不请求模型。密钥和代理认证信息在主进程加密保存，编辑时留空保留原值；勾选清除密钥才会删除已有 Key。
8. 点击 **测试连接** 会发出两轮模型请求，验证工具调用及工具结果回传，可能消耗费用。测试也经过工作台的账号并发、预算预约和结算，结果会计入“用量与预算”。

连接停用后不能开始新运行。修改连接会停止使用旧配置的活动运行；删除仍被角色引用的连接会被拒绝，先调整相应角色。

## 3. 创建角色卡片

1. 点击左侧 **Agent 角色**。
2. 点击下方的 **主 Agent / 前端工程师 / 后端工程师 / 测试工程师 / 代码审查员** 模板，或点击 **新增角色**。
3. 填写名称、职责、系统角色提示词。主 Agent 和审查模板要求依据已确认方案评审，新想法只能作为非阻塞建议。
4. 选择已保存的连接及其模型，再勾选角色的工具能力。
5. 打开 **启用角色**，点击抽屉右上角 **保存角色**。暂未绑定连接时可先保存为停用。
6. 回到卡片可查看绑定、工具和修订号，也可编辑或删除。保存角色变更会撤销该角色的活动运行，已有历史记录保留。

工具勾选是角色能力配置。`write_file`、`run_command`、派工和审查等名称为后续执行器准备，当前不会因此获得写入或命令权限。未来还需要任务合同和执行器检查目录边界。

## 4. 进行只读试运行

1. 在已启用的角色卡片点击 **试运行**。
2. 选择关联项目，填写本次输入，例如“请阅读已确认方案，概括前端职责”。
3. 选择资料范围。**角色提示词与本次对话** 不开放项目摘要读取；**另允许读取项目与确认方案摘要** 才会开放对应只读信息。
4. 点击 **开始试运行（消耗 API 额度）**。面板展示状态、输出和请求尝试次数。
5. 需要停止时点击 **取消运行**；关闭抽屉不会取消后台运行。
6. 可从历史选择框查看记录。重启后未完成运行标为中断，不自动重复付费请求；需要继续时点击 **继续运行（可能再次计费）**。配置已变化或额度不满足时可能无法继续。

试运行只开放角色允许且资料范围允许的 `read_project`、`read_plan`、`list_roles`、`get_status` 子集，不读取任意源码、不写文件、不执行命令。输出是连接和角色的验证结果，不是开发交付成果。

## 5. 设置备用模型

默认关闭。需要时，在角色编辑页展开 **备用模型与自动切换**：

1. 打开 **允许自动切换**，选择 1–4 个候选连接与模型。
2. 指定允许向候选连接发送的资料范围。
3. 设置币种及正数的额外费用上限，候选模型需配置可用价格。
4. 保存角色。折叠该区域再保存也会保留配置。

只有符合条件的临时故障会触发有限重试或备用切换。认证、权限错误不会触发自动换账号。备用策略仍受账号并发、资料范围和总预算约束。

## 6. 查看用量和预算

点击左侧 **用量与预算 → 刷新**。服务报告的 tokens、估算 tokens、未知用量请求、费用未确认请求和未确认预留分别显示。费用根据请求时保存的价格快照计算；不是服务商账单，也不是账号余额。

点击 **设置自定义预算**，选择 CNY 或 USD，设置金额、打开启用开关并保存。预算按当前工作台账本的累计已计费用与预留控制，没有自动月度重置，也不跨币种换算。启用预算后，价格未知的请求会停在预约阶段；较小余额也可能因保守预留不足而无法开始请求。

取消、超时或没有完整用量的请求可能已经产生服务商费用，因此保留未确认预留，不会显示成免费。当前未接入服务商余额、订阅额度或账单对账；应结合服务商控制台核对。独立 CLI `api-probe` 和 `live-deepseek-probe.py` 不计入桌面账本。

## 7. GPT 与 Claude 订阅账号

点击左侧 **订阅账号**。GPT 卡片可检测官方 CLI、检测登录状态；点击 **登录 ChatGPT** 后会在系统浏览器打开官方授权。可以取消等待、退出工作台账号，或重新登录切换账号。

授权使用工作台专用 `native-accounts/codex/` 目录和官方工具的系统 keyring 存储，不读取其他 Codex 目录，密码和令牌不进入角色卡片。沿用本机路由及 TUN；本机需具备可用的官方 CLI 和系统 keyring。当前仅完成官方空账号握手验证，真实登录、续期及推理未验收；登录成功后也暂不能绑定为开发执行连接。

Claude 登录按钮保持关闭，等待住宅代理下浏览器、CLI、刷新和推理全链路的强制出口验证。API 的“指定代理”不代表这项验证已经通过。

## 8. 备份与当前边界

正常退出工作台后备份整个数据目录。SQLite 保存角色、运行检查点和用量，连接凭证另行加密，官方账号令牌由系统 keyring 管理，换机通常需要重新授权或填写密钥。不要把运行数据上传 Git。

本版为未签名 macOS arm64 开发包。主 Agent 与用户持续讨论需求、自动拆任务、隔离并行开发、审查退回和集成是后续阶段；详细完成状态见 [M2 实施记录](./m2-report.md)。
