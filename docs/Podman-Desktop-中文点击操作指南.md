# Podman Desktop 中文点击操作指南

适用：这台 Mac 上已安装的 Podman Desktop 1.30.5 / Podman 6.1.4。界面和截图核对日期：2026-10-22。

**每天使用只要做这三件事：连接 D 盘 → 打开 Podman Desktop → 确认显示绿色 RUNNING。**

这里启动的是工作台所需的容器运行环境。启动 Podman 不会自动启动 agent-workbench，也不会自动开始 Agent 任务。

## 1. 先打开软件

1. 确认 D 盘已经连接，访达中能看到 **D**。
2. 点击 Mac 程序坞里的 **访达 / Finder**，图标是蓝白色笑脸。
3. 点击屏幕顶部菜单栏里的 **前往**。
4. 点击 **前往文件夹…**。
5. 在弹出的输入框中粘贴下面这条路径，再点“前往”或按回车：

   ```text
   /Volumes/D/Applications
   ```

6. 找到 **Podman Desktop.app**，双击打开。访达也可能隐藏 `.app` 后缀，只显示 **Podman Desktop**。

程序实际放在 **D 盘的 Applications 文件夹**。如果软件已经打开，直接进行下一节。

## 2. 找到启动控制页面

1. 看软件窗口最左侧，找到**左下角的齿轮图标 Settings（设置）**，点击它。
2. 页面中间会出现设置导航栏，点击最上面的 **Resources（资源）**。
3. 看右侧最上方的 **Podman** 卡片。
4. 卡片右半边有 **Podman Machine**，这就是已经创建好的运行环境，机器名是 `podman-machine-default`。

下面这张图是你本机的实际页面。左下角是 Settings，中间选中了 Resources，右侧最上方是要操作的机器卡片。

![设置与资源页面，机器卡片下方有启动、重启和停止按钮](/Volumes/D/supad/agent-workbench/docs/images/podman-guide/02-resources.png)

## 3. 点击启动，并确认成功

先看 **Podman Machine** 下方的状态，再决定是否点击。

| 当前看到的状态 | 意思 | 应该怎么操作 |
| --- | --- | --- |
| **OFF** | 已关闭 | 点击机器卡片下方按钮条里的第一个 **▶ Start（启动）** |
| **STARTING** 或转圈 | 正在启动 | 等待状态变化，不用反复点击 |
| 绿色 **RUNNING** | 已经运行 | 启动完成，可以使用容器环境 |

### 按钮条怎么认

机器卡片右半边的下方，有一条深色的横向按钮栏。当前版本的按钮从左到右是：

| 顺序 | 图标 / 名称 | 用途 |
| --- | --- | --- |
| 第 1 个 | **▶ Start** | 启动机器 |
| 第 2 个 | **↻ Restart** | 重启机器 |
| 第 3 个 | **■ Stop** | 停止机器 |
| 第 4 个 | 编辑图标 / **Edit** | 修改机器配置 |
| 第 5 个 | 垃圾桶 / **Delete** | 删除机器，日常启动用不到 |
| 第 6 个 | **⋮** | 更多操作 |

把鼠标放在图标上停留，可以查看按钮提示。

**截图中的 ▶ 是灰色，这是正常的：截图拍摄时已经显示绿色 RUNNING，所以无需再次启动。**

日常启动操作用机器卡片下面的 **▶**。左边紫色的 **Create new…（新建）** 和齿轮设置按钮用于另外的操作；本机已经有机器，不需要重新创建或安装。

## 4. 在首页查看运行状态

也可以从首页确认是否启动成功：

1. 点击窗口左上方导航中的 **Dashboard（首页）**。
2. 在右侧页面向下滚动，找到 **Podman v6.1.4** 卡片。
3. 看到绿色圆点和 **RUNNING**，说明容器环境已经启动。

下图就是运行成功的状态。Podman 状态卡片在首页比较靠下的位置，上面的教程和推荐内容可以跳过。

![首页向下滚动后，Podman 卡片显示绿色 RUNNING](/Volumes/D/supad/agent-workbench/docs/images/podman-guide/01-dashboard.png)

## 5. 为什么 Containers 页面没有东西

左侧 **Containers（容器）** 显示的是具体容器任务；**RUNNING** 显示的是运行这些容器的机器已经启动。

因此，机器已经 RUNNING，但 Containers 列表为空，是正常情况：当前没有具体容器任务。你不需要为了“启动成功”去点击 Create Container 或随意创建容器。

后续工作台完成 Podman 接入后，才会按任务需要创建、运行和清理对应容器。目前安装完成并通过了基本容器测试，工作台的完整接入仍在开发中。

## 6. 用完后怎么停止、退出

### 停止运行环境，释放内存

1. 先保存工作，确认工作台没有正在执行的容器任务。
2. 点击左下角 **Settings（设置）**。
3. 点击 **Resources（资源）**。
4. 在最上面的 Podman Machine 卡片下方，点击第 **3** 个按钮 **■ Stop（停止）**。
5. 等到状态变成 **OFF**。

停止机器会中断里面正在运行的容器。停止不会删除已有镜像和容器数据，下次还可以用 **▶ Start** 启动。

### 退出桌面软件

如果希望连桌面窗口也一起退出，在上一步确认 **OFF** 后：

1. 点击一下 Podman Desktop 窗口，让它成为当前应用。
2. 点击 **Mac 屏幕最上方菜单栏**里的 **Podman Desktop**。
3. 点击 **Quit Podman Desktop（退出 Podman Desktop）**。

窗口左上角的红色 **×** 不能作为机器已停止的判断依据。想释放虚拟机占用的资源，先按上面的步骤确认 **OFF**。

需要拔掉 D 盘时，也先停止机器并退出软件，然后在访达中正常推出 D 盘。

## 7. 常见情况怎么处理

| 遇到的情况 | 处理方法 |
| --- | --- |
| 找不到 Podman Desktop | 按第 1 节进入 `/Volumes/D/Applications`，双击打开 |
| 找不到启动按钮 | 进入 **Settings → Resources**，查看最上方 Podman Machine 卡片下面的 **▶** |
| 启动按钮是灰色，同时显示 RUNNING | 已经启动成功，无需再点 |
| 一直显示 STARTING，几分钟后仍没变化 | 截图当前状态；如果出现失败提示，点开查看错误文字后发给我 |
| 显示 NOT-INSTALLED、出现 Install 或 Set up 提示 | 先确认 D 盘已连接；本机已配置 D 盘引擎，暂时不要重新安装，截图提示发给我核对 |
| 窗口关闭了，但感觉仍占内存 | 重新打开软件，到 **Resources** 查看机器是否仍是 RUNNING；要停止就点 **■ Stop** |
| Containers 是空列表 | 没有具体容器任务，和机器是否启动是两回事；到 Resources 查看状态 |

本指南依据当前本机界面编写。软件升级后图标或位置可能变化，优先认准 **Settings、Resources、Podman Machine、Start、Stop、RUNNING、OFF** 这些文字。
