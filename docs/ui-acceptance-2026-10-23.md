## 修复与复验

首次无效代理保存时，Go 的底层英文校验消息被直接展示。原因是 `/api/proxies/validate` 将解析错误原文交给通用错误响应；改为该用户接口提供中文格式说明，保留底层解析器与拒绝行为。

更新包后在实际窗口重新输入无效代理，显示中文的协议、主机、端口和认证填写提示，连接修订仍为 2，未保存错误值。原有 API 负例进一步验证错误不包含合成代理用户名和密码。

`python3 scripts/dev.py verify`、`python3 scripts/dev.py lint` 和 macOS 应用重新打包通过。正常退出的应用进程返回 0；测试数据保留在忽略目录便于复核，不提交 Git。

本轮没有点击“测试连接”，没有调用 DeepSeek 或公司服务。GPT/Claude 订阅登录、Claude 强制住宅出口和多 Agent 开发闭环仍未完成。Electron 提示同步 safeStorage API 已弃用，本轮实际加解密及重启通过；异步 API 迁移应在后续凭证服务完善时处理，不据此声称换机解密或长期兼容性已验证。
