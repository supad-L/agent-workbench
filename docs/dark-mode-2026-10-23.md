# 深色模式实施记录

日期：2026-10-23。用户要求加入深色模式，同时保留图标候选、暂不替换正式图标。本轮不改变 M2 原生接入的验收状态。

## 行为与入口

- 侧栏底部“外观”提供跟随系统、浅色、深色三档。首次默认跟随系统，手动选择立即生效，并保存在当前工作台本地应用存储中。
- 跟随系统时监听系统深浅变化；手动浅色/深色优先于系统。切换只更新显示，不重载页面、不丢失表单输入，也不检查账号或发起模型请求。
- 页面布局、文字、边框、选中态与卡片使用共享 CSS 配色变量；表单、表格、下拉菜单、弹窗、抽屉及提示使用同一 Ant Design 主题上下文。深色使用深海军蓝分层面板、浅色文字和冷蓝强调色。
- 渲染前应用保存的偏好；窗口等到绘制就绪后显示。受既有主进程 IPC 来源检查保护的 `appearance.set` 仅接受 system/light/dark，用于本应用原生外观和窗口底色，不修改操作系统主题。
- 存储不可写时，本次切换仍有效，并显示本次偏好无法保存的说明。无法读取或损坏的值回退跟随系统。

实现入口：`web/src/appearance.tsx`、`style.css`、`main.tsx`、侧栏的 `AppearanceControl`，以及 `desktop/appearance.cjs` 和受限 IPC。偏好键为 `agent-workbench.appearance.v1`，其中只有显示模式，不保存账号或凭证。
