# M2 原生会话持久化与显式恢复

日期：2026-10-23。实现用户选定的第一项：独立运行目录、原生会话编号、持久检查点与重启状态。**本轮仅验收离线实现及合成原生协议，没有完成真实 GPT/Claude 账号或在线编码验收。**

## 已实现

- SQLite schema 5 增加 `native_sessions`、`native_attempts`，保存逻辑会话、固定模型/镜像/源快照绑定、方案版本、每次执行尝试及规范化检查点。
- `state/native-runtime/<工作台会话 ID>/codex/` 存放各会话独占的 CLI 状态。容器只挂载自己的状态子目录，HOME/cache/tmp 保持临时隔离，网络仍为 none，没有挂载宿主账号目录。
- 会话启动前先事务领取执行尝试，再保存随机容器身份。幂等键重放不重复启动；检查点有尝试代际与递增序号，旧回调、冲突重放及跳号会被拒绝，已完成尝试保持只读。
- 规范化检查点包括原生会话编号、草稿、已报告/未知用量及提供方终态。原始 prompt 不写入新的尝试表，仅保存请求摘要；完整对话仍属于私有原生状态。没有将原始 stderr、命令或工具参数作为普通运行日志。
- 续接必须提供固定会话编号和新的显式输入，创建新的执行尝试；不使用 `--last`，不重放旧 prompt，不自动重新推理。
- 续接前核对原生 rollout 文件、完整状态摘要、只读源快照摘要和确认方案版本。文件丢失/变化、符号链接或依据变化不会被静默放行。可写任务目录仍由调用方准备并沿用固定权限，M3 正式副本/合同/调度尚未接通。
- 服务关闭会取消活动执行并保存结果；重启仅核对既有日志、停止/清理已登记容器并记录状态，不创建或续接任何模型进程。无法确认结果时保持 uncertain。

核心代码：`internal/nativeservice/`、`internal/store/native.go`、`internal/runtime/codex/`、`internal/sandbox/execute.go`。

## 恢复判定

| 已有证据 | 状态与后续 |
| --- | --- |
| 尝试已领取，但尚未写入启动身份 | 中断于启动前；不自动执行，可由新的显式动作处理 |
| 提供方成功终态、零退出和清理均确认，匹配会话文件/摘要仍在 | 上次回合完成；本地续接条件齐备，下一次用新输入创建新尝试 |
| 正常取消/超时后已确认停止，原生会话文件完整 | 已中断；本地续接条件齐备，保留草稿和历史 |
| 容器启动已登记后平台进程异常终止 | 结果未知；即使清理成功或收到过提供方终态，也不自动认为已完成/可续接 |
| 清理、状态文件、源快照或方案依据无法核对 | 不允许按旧记录续接，显示缺失条件；未知结果不按零用量处理 |
| 续接在启动前因运行时未就绪而停止 | 保留原会话编号和状态摘要，避免误变成全新会话 |

`can_resume` 只说明本地续接证据；`live_ready` 本轮始终为 false。仅有原生会话编号或存在日志文件不够，需要找到匹配该编号的 `sessions/*<ID>.jsonl` 常规文件并复核摘要。CLI 版本改变该约定时按证据不足处理，不搜索其他账号目录。

## 只读界面与接口

项目页新增“原生会话”标签，可查看状态、恢复条件、独立目录、原生编号、草稿、尝试历史和检查点序号。当前仅能刷新/核对，启动与继续按钮未开放；没有凭空添加示例到用户项目。

- GET `/api/projects/{id}/native-sessions`
- GET `/api/projects/{id}/native-sessions/{session}`

两者仅供本地人类身份使用，受原有认证/Origin 检查与项目绑定约束。没有新增原生启动、续接或任意容器配置的 HTTP/IPC 操作。桌面只增加对应两个只读 IPC。

## 验证与证据范围

1. 单元/存储：幂等动作、单一领取、检查点去重与顺序、旧代际拒绝、尝试历史、确认方案切换、文件变化/丢失/链接、取消收尾、状态分类、schema 4→5 保留既有 API 运行和角色。
2. 真实 Podman：使用本机已存在 Alpine 不可变镜像，容器内执行明确标识的合成 CLI 脚本。关闭并重新打开数据库/管理器后，第二次按保存编号续接成功；重复相同动作保持总执行次数为 2。
3. 真实强制中止：独立平台测试进程写入草稿检查点后被 SIGKILL；重新启动管理器仅核查并清理原容器，记录为 uncertain，草稿保留，合成 CLI 执行次数仍为 1，没有启动第四次/重复请求。
4. 实际后端进程：独立服务重新打开同一持久夹具，只读 HTTP 返回一个本地可续接会话与一个未知结果会话，各自保留 2/1 次尝试和 2/1 次合成执行计数；读取前后计数不变。
5. Go gofmt/vet/全量 race/编译/合同/协议/网络探针与 lint 通过；22 项 UI、14 项桌面测试、TypeScript/生产构建、macOS arm64 打包及启动/重启冒烟通过。Go 合并覆盖率约 80.7%。
6. **新标签页实际桌面点击与视觉复核未执行：Mac 锁屏，电脑工具无法访问窗口。** 只读页面的状态展示、禁用继续及项目切换通过 UI 自动测试；未用自动测试冒充实际桌面视觉验收。独立 QA 应用已停止。

可保留的独立夹具位于忽略目录 `output/ui-native-session-qa-20261023/`，其中 `result.json` 为脱敏只读服务验收摘要；不是用户工作数据，没有真实账号、付费调用或宿主裸跑用户项目。Docker 本轮只做合成编排验证，不宣称真实 Docker 通过。发布包仍未签名/公证。
