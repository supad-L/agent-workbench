# M0 可行性与证据分级

日期：2026-10-22。本文记录当前实现，不把计划中的能力写成已支持。

| 假设/目标 | 当前状态 | 证据与边界 |
| --- | --- | --- |
| 三种 API 可归一为文本与工具回合 | 合成验证通过 | 本机 HTTP 服务验证 Messages、Chat Completions、Responses 的两轮调用；未访问真实服务 |
| Base URL 和完整端点可以正确配置 | 单元验证通过 | 包括 /v1、已有完整路径、公司前缀与显式本地 HTTP |
| 不完整流不能变成可执行工具结果 | 单元验证通过 | 截断、缺终态、错误、非法 JSON、未授权工具、取消等场景 |
| 固定方案、任务和审查能结构化检查 | 合同/guard 验证通过 | 未实现数据库确认与语义审查，不能把结构通过等同业务正确 |
| 多 Agent 消息有一致身份 | 合同/guard 验证通过 | 项目/任务/attempt/代际与已认证主体匹配；持久邮箱、回执和调度尚待后续实现 |
| 账号别名不会产生不同资源身份 | 指纹验证通过 | 相同服务和相同 Key、相同已验证主体产生稳定资源键；实际认证与调度尚未接通 |
| 修改范围可以生成可执行目录策略 | 单元验证通过 | 路径、前缀冲突、只读源别名、链接、完整差异和补丁基线检查 |
| 容器组合挂载可真正阻止越界 | Podman 真实基础探针通过 | 已验证允许目录、只读源、链接逃逸、根文件系统、私有 tmp 及清理；Docker 兼容路径和自动测试保留，本机不使用 Docker Desktop，尚无本轮真实 Docker 证据；完整执行器/网络反例另行验收 |
| GPT 订阅登录可用于正式开发 | 未验证 | 仅发现 CLI 可执行文件；没有读取登录文件、请求模型或验证权益 |
| Claude 订阅登录可用于正式开发 | blocked / 未验证 | 本机未发现 Claude CLI；接入授权范围与真实运行尚待核验 |
| 指定代理故障不回退直连 | 应用 HTTP 层合成验证通过 | 本地代理失效后目标直连计数保持零；不代表浏览器、CLI或所有网络协议已被隔离 |
| 账号网络快照、撤销与认证修订 | 核心原语/回环验证通过 | 旧 HTTP 会话关闭后拒绝复用并取消流，其他会话继续；正式账号别名归并、保存变更事务与登录服务未接通 |
| DeepSeek API 基本工具回合 | 合成通过；用户报告真实通过 | 用户回传 requests=2、tool_verified=true、usage_known=true；来源为用户本机执行，助手未读取 Key 或重复发出付费请求 |
| Claude 登录与执行统一住宅出口 | blocked | 强制出口隔离器尚未实现；enforced_proxy 返回未就绪，不能以普通代理宣称保证 |
| GPT 和公司中转沿用 Clash/TUN | 待真实连接验证 | 用户截图显示系统代理、虚拟网卡和规则模式；未向公网检测地址发出请求 |

M0 当前可交付合同和原型代码，但整体尚未通过。按既定阶段依赖，先补齐真实隔离与接入证据，再宣布进入完整业务实施阶段。
