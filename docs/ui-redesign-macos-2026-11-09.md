# 桌面界面重构执行方案：macOS 风格 · 2026-11-09

用户在 2026-11-09 指出现有界面“太丑、不方便使用”，要求改为 macOS 审美风格，并要求先写执行文档再重构。本文是这次重构的执行依据，属于实施记录，不修改根目录四份方案文档中的产品要求与验收条款。

## 1. 范围与不变项

**本次只改表现层与交互组织**：窗口外壳、配色/字体/间距令牌、导航与页面布局、组件样式、说明文字的呈现方式，以及把被压成长单行的前端代码整理为可读格式。

以下内容**保持不变**，重构不能借机改动：

| 不变项 | 说明 |
| --- | --- |
| 技术栈 | Electron + React + TypeScript + Ant Design（用户 10-22 指定），不引入新的 UI 框架或依赖 |
| IPC 与后端 | `window.workbench.invoke` 操作名、参数、预加载白名单、Go API 均不改 |
| 安全与计费语义 | “消耗 API 额度”“可能再次计费”“原生编码尚未开放”“未知费用不按零处理”等提示必须仍然可见；只能换位置和样式，不能删除 |
| 显式触发 | 登录、检测、测试连接、试运行仍只在用户点击时发生，导航与切换外观不触发任何请求 |
| 异步保护 | 表单代际保护、晚到结果丢弃、隐藏表单字段保留（`getFieldsValue(true)`）等既有修复全部保留 |
| 角色卡片列数 | 正常窗口每行三张，1100px 以下两列，760px 以下一列；不改回 auto-fit（交接文档明确要求） |
| 功能边界 | 不新增功能、不暗示 M3/M4 能力已可用 |

## 2. 现状问题

依据 10-23 至 10-27 的 QA 截图和源码：

1. **不像桌面应用**：使用系统标准标题栏，内容区是网页后台式的白卡片 + 大标题头，没有原生窗口的工具栏、侧栏半透明和红绿灯整合。
2. **视觉噪音大**：几乎每页顶部都有大块蓝色说明框；状态全部用彩色 Tag；字号、行高偏大（行高 1.8–1.9），信息密度低。
3. **导航不顺手**：项目列表只在“项目工作区”出现，切到其他页就消失；外观选择、阶段标签、版本说明塞在侧栏底部。
4. **页面结构松散**：连接页三段式（接入方式条 + 列表 + 长表单）层级不清；用量页是一张需横向滚动的宽表；账号页卡片与检测表单堆叠。
5. **代码难维护**：`workbench.tsx`、`project-view.tsx`、`connections.tsx`、`style.css` 等被压成少量超长行，后续每次修改都容易出错。

## 3. 设计方向

参照 macOS Sonoma / Sequoia 的“系统设置”“访达”“Xcode”：

- **窗口**：隐藏标题栏、红绿灯内嵌（`titleBarStyle: 'hiddenInset'`），侧栏使用系统半透明材质（`vibrancy: 'sidebar'`），内容区顶部是可拖动的统一工具栏。非 macOS 平台退回不透明背景。
- **布局**：左侧源列表（Source List）+ 右侧内容；需要“列表—详情”的页面（连接）使用中间列表栏，类似“邮件”。
- **表单**：采用“系统设置”式的**分组圆角列表**（Grouped Inset List）：每组一张圆角卡片，行之间是发丝分隔线，标签在左、控件在右；长文本输入独占一行。
- **说明文字降噪**：页面级长说明改为标题旁的 ⓘ 提示或分组底部的灰色脚注；只有真正的警告（如绑定连接已停用）才用醒目颜色。计费/安全相关提示保留在操作按钮附近。
- **状态表达**：用小圆点 + 文字的状态标签（绿=就绪/通过，橙=待处理/未知，灰=未开始/禁用，红=失败），减少彩色色块。
- **克制的动效**：仅保留选中、悬停的细微过渡；遵守 `prefers-reduced-motion`。

### 3.1 设计令牌

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--accent` | `#007AFF` | `#0A84FF` | 系统强调色：主按钮、选中、链接 |
| `--bg-window` | `#FFFFFF` | `#1E1E1E` | 内容区背景 |
| `--bg-grouped` | `#F5F5F7` | `#181818` | 设置类页面背景 |
| `--bg-card` | `#FFFFFF` | `#2A2A2C` | 分组卡片 |
| `--bg-sidebar` | 半透明（无材质时 `#ECECEE`） | 半透明（无材质时 `#232325`） | 侧栏 |
| `--label` / `-2` / `-3` | `rgba(0,0,0,.85/.55/.28)` | `rgba(255,255,255,.88/.55/.28)` | 主/次/弱文字 |
| `--separator` | `rgba(0,0,0,.1)` | `rgba(255,255,255,.1)` | 分隔线 |
| `--fill` | `rgba(0,0,0,.05)` | `rgba(255,255,255,.07)` | 控件底、悬停 |
| 状态色 | 绿 `#34C759` 橙 `#FF9500` 红 `#FF3B30` | 绿 `#30D158` 橙 `#FF9F0A` 红 `#FF453A` | 状态点 |

- 字体：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`；正文 13px，行高 1.5；页面标题 20px/600，分组标题 13px/600，脚注 11–12px。
- 圆角：控件 6px，分组卡片 10px，大面板 12px。控件高度 28px（大按钮 32px）。
- Ant Design 通过 `ConfigProvider` 主题令牌对齐上述数值（`fontSize: 13`、`controlHeight: 28`、`borderRadius: 6`、去除按钮阴影），并为 Segmented、Table、Tabs、Card、Drawer、Modal 设组件级令牌。

### 3.2 信息架构

**侧栏**（宽 232px，红绿灯下方留出 52px）：

```text
项目                      [+]
  ▸ 项目 A
  ▸ 项目 B
配置
  模型连接
  Agent 角色
  订阅账号
监控
  用量与预算
──────────────
[⚙ 设置]           v0.1.0 · M2
```

- 项目列表常驻，点击任一项目进入项目页；“+”新建/导入项目。
- 外观（跟随系统/浅色/深色）移入底部“设置”弹出面板，用分段控件切换。
- 阶段说明压缩为一行小字。

**各页面**：

| 页面 | 新结构 |
| --- | --- |
| 欢迎页 | 居中图标 + 一句话说明 + “新建项目”主按钮 |
| 项目 | 工具栏：项目名、方案状态点、分段控件（需求与方案 / 资料 / 原生会话 / 事件）、“…”更多菜单（验证权限边界）。“需求与方案”左右两栏：左侧是对话式需求记录（气泡 + 底部输入框），右侧是文档式方案视图（版本选择、状态、分节内容、操作区） |
| 模型连接 | 中间栏：接入方式切换 + 已保存连接列表（名称、协议、模型、状态点）+ 存储说明脚注；右侧详情：配置进度条、分组表单（基本信息 / 认证 / 网络 / 高级），底部固定操作栏 |
| Agent 角色 | 工具栏右侧“新增角色”；已配置角色为三列卡片（顶部类型色条改为左侧圆形类型图标）；模板为浅色虚线卡片 |
| 用量与预算 | 顶部统计卡（已知费用、未确认预留、已报告 tokens、未知/未计价请求），下方按币种明细表与预算、服务商额度分组列表 |
| 订阅账号 | 接入方式切换；每个账号一个分组列表（官方工具、授权、编码执行、账号占用），操作按钮在组底；执行环境检测为单独分组表单，结果以分组列表呈现 |
| 抽屉/弹窗 | 编辑类保持右侧抽屉（视作检查器面板），新建项目、预算保持弹窗（视作 sheet），统一圆角、标题栏与底部按钮位置 |

## 4. 代码组织

```text
web/src/
  styles/tokens.css      设计令牌（浅/深/跟随系统）
  styles/base.css        重置、字体、滚动条、窗口拖动区
  styles/layout.css      侧栏、工具栏、页面容器、分栏
  styles/components.css  分组列表、状态点、卡片、各页面局部样式
  ui.tsx                 共享展示组件：Toolbar、Page、Group/Row、StatusDot、InfoTip、EmptyState
  appearance.tsx         主题令牌与外观设置（分段控件）
  其余页面组件           保持现有文件名与导出，逐个重写为可读格式
```

- 页面组件的文件名、默认导出和 props 不变，便于测试与调用方保持稳定。
- 删除原 `style.css`；每个页面的局部样式集中在 `components.css` 中按页面分段。
- `desktop/main.cjs` 只改 `BrowserWindow` 外观参数；`desktop/appearance.cjs` 在 macOS 上使用透明窗口背景以保留侧栏材质。渲染层通过 User-Agent 识别 macOS，在 `<html>` 上标记 `data-platform="mac"`，用于红绿灯留白与半透明侧栏。

## 6. 验证

1. **界面测试**：现有 9 个测试文件全部保留其行为断言（不发起登录/模型请求、代际保护、凭证不进入表单提交等）。只因控件形态变化而调整定位方式（例如外观从下拉框改为分段控件），不删除行为断言。
2. **类型与构建**：`tsc --noEmit`、生产构建通过。
3. **视觉核对**：使用合成数据的界面预览，分别截取浅色、深色下 1320×900 与最小窗口 960×680 的主要页面，检查对齐、截断、对比度与空状态。
4. **桌面核对**：在 Mac 上执行 `python3 scripts/frontend.py test:ui`、`test:desktop`、`build:ui`、`package:mac` 与 `python3 scripts/desktop-smoke.py`，确认红绿灯位置、拖动区与侧栏材质。

本次开发环境的限制：开发助手所在环境无法安装本项目的 macOS 原生前端依赖，因此第 6.1、6.4 项需在用户 Mac 上运行；助手侧以同版本 Ant Design/React 打包的预览页完成截图核对，并以此说明证据范围，不把预览截图写成桌面实测。

## 8. 实施记录（2026-11-09）

U1–U7 已按本文实施，产品行为、IPC 与后端未改动。

- **窗口外壳**：macOS 上 `titleBarStyle: 'hiddenInset'`、红绿灯位于 (18, 18)、侧栏 `vibrancy: 'sidebar'`、窗口背景透明；其他平台保持不透明背景（浅 `#ffffff` / 深 `#1e1e1e`）。`desktop/appearance.cjs` 在 macOS 上始终设透明背景，测试新增对应用例。渲染层按 User-Agent 标记 `data-platform="mac"`（红绿灯留白）与 `data-vibrancy`（仅 Electron on macOS，透明页面背景）。
- **样式与组件**：删除 `style.css`，改为 `styles/tokens.css`、`base.css`、`layout.css`、`components.css`；新增 `ui.tsx`（Toolbar、Page、Group、Row、Status、InfoTip、Notice、EmptyState）。Ant Design 主题令牌与第 3.1 节一致。
- **导航**：侧栏分组为 项目 / 配置 / 监控，项目列表常驻；外观移入底部“设置”弹出面板（分段控件，`aria-label="外观模式"`）。
- **页面**：项目页为工具栏分段切换 + 左右分栏（对话气泡 / 文档式方案）；模型连接为列表 + 分组表单 + 底部操作栏，接入方式成为工具栏分段切换；角色卡片保持 3/2/1 列；用量页增加统计卡；账号页为两张账号卡 + 分组式环境检测。计费、未验证、禁用登录等提示均保留，长说明移入 ⓘ 提示或分组脚注。
- **代码格式**：所有被重写的页面组件已展开为可读的多行格式，文件名、默认导出与 props 不变。
