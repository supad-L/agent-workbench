## 2. 产品目标与约束

用户与主 Agent 聊需求、资料及方案；确认后由主 Agent 给前端、后端等角色派工，允许隔离并行开发；主 Agent 对照方案审查，不通过则退回原执行者修改，最终集成。支持从零开发、修改已有项目、新增需求。

桌面使用 Electron、React、TypeScript、Ant Design，后端 Go + SQLite。图标为无限符号及两侧连接线，已经交付。API 支持 GPT、DeepSeek、国内 Coding Plan、公司自定义中转等；原生 GPT/Claude 订阅登录与执行仍是保留需求。

用户偏好 D 盘存放项目、工具、大型运行数据。公司禁用 Docker Desktop，但产品同时保留 Docker 和 Podman 支持；本机采用 Podman。自动执行用户代码必须隔离，不能退回宿主裸跑。

GPT 默认跟随本机路由/VPN/TUN。公司中转可用自定义 Base URL、协议与本机 DNS。Claude 要求独立住宅代理出口，并覆盖登录浏览器、CLI、续期和推理，故障不能回退直连；普通代理开关不能宣称实现该保证。不要修改用户全局 Clash 设置。

## 3. 当前已交付

**M1 已完成；M2 的 API、角色、运行与预算核心已实现，M2 整体尚未验收完成。**

- M1：项目新建/导入副本、需求记录、文档导入、方案草案/确认锁定/变更、权限与事件恢复。需求页目前是手工记录，真实主 Agent 持续对话尚未接通。

- M2 角色：五类模板和自定义角色，提示词、连接/模型、工具、启停、备用候选/资料范围/额外费用上限。

- M2 预算：报告/估算/未知用量区分、手工价格快照、请求前预约、幂等结算、未知费用保留。桌面“测试连接”也使用同一账本；独立 CLI 探针不使用此账本。余额和订阅额度仍未知。
- GPT 官方授权入口：独立 CODEX_HOME、官方 app-server 账号方法、要求系统 keyring、单一管理子进程。仅验证本机官方 CLI 的空账号握手；没有由开发助手执行真实账号登录、刷新或推理。
- Claude：登录和原生执行保持禁用，等待强制出口验收。
- 最新布局：已配置角色在正常窗口固定每行三张，只有一张也只占一列；1100px 以下两列、760px 以下一列。卡片内边距收紧，长名称/模型名省略，悬停查看全文。不要改回 auto-fit 导致单张铺满。
