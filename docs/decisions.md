## 网络使用方式

用户要求 Claude 订阅账号可单独绑定代理出口（例如住宅代理）；GPT 优先沿用本机 VPN 网络；国内服务和公司中转可配置独立 Base URL、API 和网络策略。

用户提供的截图显示系统代理和虚拟网卡均开启，使用规则模式。未保存截图中的出口 IP 或内网地址；没有读取或修改 Clash 配置。

据此采用以下实现约束：

1. system：沿用操作系统路由及当前 TUN 分流；不声称已验证 VPN 出口，也不自动读取 macOS 系统代理 UI 配置。
2. explicit_proxy：工作台请求显式经过选定代理；目标域名由该代理处理。代理失败不能回落直连。
3. enforced_proxy：要求登录浏览器、官方执行器、续期与推理都在验证过的出口约束下。仅有环境变量或 HTTP transport 不算完成；当前尚未实现该隔离器，代码明确拒绝将它视为可运行。
4. 公司中转优先由本机网络服务发起 Messages 协议请求，沿用本机网络/DNS或显式配置 Clash 代理。实际域名、端口、认证、工具协议尚需用户配置后验证。
5. 登录前需要选定 Claude 的出口；之后切换出口不能撤回此前连接记录。公网出口约束与隐藏所有客户端/设备信息是不同能力。

上述约束不增加目标软件中的人工审批环节，不修改用户的全局代理、DNS或VPN设置。真实账号验证和网络规则安装尚未执行。
