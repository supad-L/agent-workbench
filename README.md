版本：0.1，方案已于 2026-10-22 获用户确认并开始实施。日期：2026-10-22，Asia/Shanghai。

项目名称：agent-workbench。已实现 M1 项目与方案基础，以及 Electron / Ant Design 桌面界面和通用自定义 API 配置页。

本文档包把本次沟通转成可开发、可验收的方案；用户已明确确认当前方案并授权编码。原方案条款保留，实施事实单独记录。未修改 agentbox；助手未读取真实账号凭证或重复付费调用，DeepSeek 真实验证依据用户回传报告记录。

当前可新建/导入项目、保存需求和资料、编辑并确认锁定方案、提出变更草案、恢复事件，以及配置三种协议的 API。真实 Agent 对话/派工仍待后续阶段；GPT/Claude 登录及严格出口隔离未验证。桌面入口为根目录的 `启动工作台.command`。先阅读 [中文操作指南](./docs/工作台-中文操作指南.md)、[M1 交付记录](./docs/m1-report.md) 和 [开发运行说明](./docs/development.md)。

## 1. 产品目标

用户与主 Agent 持续讨论需求、提供项目和文档；确认方案后，由主 Agent 调度可配置的专业角色并行开发，审查真实成果、退回修改、完成集成。用户参与方案制定、需求变更和确实无法判断的问题，日常派工与返工自动进行。

首版覆盖从零开发、修改现有项目、增加需求。支持自定义模型 API、国内 Coding Plan，以及 GPT / Claude 的账号登录接入目标。账号管理参考 agentbox，任务与验收机制参考 dsh-agent-teams，平台自身维护流程和权限。

## 2. 已确认的产品约束

| 编号 | 用户要求 | 必须产生的系统行为 |
| --- | --- | --- |
| R01 | 先沟通并制定方案，再派工 | 讨论中的草案不能启动开发任务；确认后生成不可修改的方案版本 |
| R02 | 主 Agent 派工、审查、评价、退回修改 | 任务、成果、问题和修改轮次持久化，失败验收不能解锁下游 |
| R03 | 配置前端、后端等角色及模型 | 角色、执行器、接入账号、模型分别配置；角色提示词可复用 |
| R04 | API 和现有编程 Agent 都支持 | 提供统一任务协议和独立接入适配器 |
| R05 | 本地运行 | 本机服务与浏览器工作台优先，项目和控制数据保存在本机 |
| R06 | API、国产 Coding Plan、GPT / Claude 登录 | 统一连接管理；每家认证方式独立适配；限制和未验证状态明确展示 |
| R07 | 并行开发且不越界 | 独立任务副本、执行期文件约束、共享资源协调、集成前范围检查 |
| R08 | 主 Agent 也必须严格遵守方案 | 正式评审依据固定版本；新增想法只能进入建议列表 |
| R09 | 不确定时先主 Agent 协调，再找用户确认 | 只等待受影响的任务；确认结论可追溯并送达相关执行者 |
| R10 | 后续持续聊新需求、调整项目 | 持续项目会话、版本化变更和任务影响分析 |

“软件开发期间向用户澄清需求”与“给目标软件新增人工介入功能”是两件事。前者按 R09 执行，后者必须属于已确认的产品方案。主 Agent 不得以稳妥、最佳实践或个人偏好为由，擅自给自动流程增加人工审批节点。

## 3. 建议采用的整体方案

- 新建独立工作台项目，借鉴参考项目的模块和机制，避免直接改造 agentbox 的全部产品结构。
- 后端采用 Go，前端采用 React + TypeScript，SQLite 保存业务状态，文件存储保存成果和日志。
- 单机、单用户、可管理多个项目；每个项目只有一个当前生效方案，旧任务与成果复用需要显式承接记录。
- 主 Agent 负责讨论、规划、调度、审查和协调；实际代码修改由有范围合同的任务执行。
- 调度器、凭证服务、工具权限、版本检查与集成由普通程序管理，主 Agent 无权绕开。
- 所有自动代码执行走隔离执行器。macOS 首选本机 Docker 运行时；缺少隔离条件时允许讨论和看代码，开发任务保持未就绪，不静默切换成裸机运行。
- 国内 Coding Plan 作为自定义 API 连接，选择协议、填写 Key、地址与模型；具体服务商可后续配置。

## 4. 需要明确的接入现实

GPT 与 Claude 登录均保留为需求。当前官方接入方式和授权范围不同，不能直接复制参考项目的 OAuth 实现后宣称已完整支持。

ChatGPT 方向优先验证官方 Codex 接入；适用时可采用面向开源、本地托管应用的官方 Sign in with ChatGPT 路径。Claude 方向分别验证官方工具原生登录与第三方产品授权范围。未经官方允许的订阅凭证复用不能当作正式完成项。具体判定在 M0 输出验证记录；若存在外部限制，保留需求并报告缺口，不擅自改成“API 就算完成”。

账号出口绑定用于控制网络路径；不能承诺消除服务商的地区、账号或使用规则限制。目录边界可以执行约束；设计语义是否偏离仍需评审，不能承诺仅靠提示词或需求编号就完全识别。

## 6. 第一版完成的含义

能够导入一个项目，与主 Agent 确认方案，配置不同连接的前后端角色，在隔离环境并行完成开发；主 Agent 依据固定方案发现问题并退回原任务修改，平台验证范围和测试，最终形成已集成的交付分支。中途可提出疑问、增加需求、切换已配置连接，并保留完整记录。

上述流程必须经过真实项目和真实接入验证。模拟测试通过、接口连通、订阅登录成功、完整开发任务成功是不同证据等级。尚未完成的 GPT / Claude 认证验收必须明确列出，不能在发布说明中写为已支持。
